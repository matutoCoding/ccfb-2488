# 皮影云坊 · 线上皮影动画工坊

给皮影剧团的网页版皮影动画制作与演出工具。Vue 3 + Three.js(WebGL)。

## 运行

```bash
npm install
npm run dev      # 开发(默认端口 5937)
npm run build    # 打包到 dist/
```

## 五个页面

| 页面 | 功能 |
|------|------|
| 角色库 | 导入分件 PNG(头/身/手/腿各一张),拖动摆放、排层级、点选关节点;可一键生成示例角色 |
| 骨骼绑定 | 点住拖出骨骼、自动权重、笔刷手刷权重(红色热力图)、关节铆钉开关 |
| 动画编辑 | 关键帧时间线(拖帧)、缓动曲线(含贝塞尔手柄)、FK 旋转、IK 拖末端、双动作混合与烘焙 |
| 演出舞台 | 幕布后打灯(远近/高低/亮度/色温),影子随灯距变大变虚;多角色同台共时间线;录制 WebM |
| 设置 | 工程改名、自动保存、导入导出 .json、帧率/透光/铆钉等渲染参数 |

## 防撕裂设计(最要紧的一条)

关节大角度转动时贴图不拉成一团、不撕开,靠四道保险:

1. **硬片优先的自动权重**:每个部件默认 100% 绑定主骨(真皮影就是硬皮片),只有关节带内的顶点按 smoothstep 渐变分给相邻骨,形变被限制在关节附近窄带内;
2. **细分网格**:每片切成 N×N 网格(可调 2~24),弯曲分摊到多行顶点;
3. **关节铆钉**:渲染时在关节处盖铆钉圆片,物理遮住残余接缝——真皮影本来就有铆钉;
4. **硬片铰接模式**:部件勾选后完全不形变,纯铰接,任何角度都绝对安全。

## 数据与复用

- 动作存为「片段」,可跨角色复用;两个片段可按比例混合并烘焙成新片段;
- 工程(含贴图 dataURL)自动存 localStorage,可导出/导入 `.shadowpuppet.json`;
- 演出通过 `canvas.captureStream + MediaRecorder` 录成 WebM 下载。

## 目录结构

```
src/
  core/
    model.js           数据模型(角色/部件/骨骼/片段/工程)
    mat2d.js           2D 仿射变换
    skinning.js        网格细分、自动权重、CPU 蒙皮、笔刷权重  ← 防撕裂核心
    ik.js              两骨 IK 解算
    animation.js       关键帧采样、缓动、片段混合/烘焙
    editorRenderer.js  编辑器渲染器(库/绑定/动画三页共用)
    stageRenderer.js   舞台渲染器(幕布纸纹、灯光、影子投影+模糊、皮质透光)
    demoCharacter.js   程序化示例角色(含骨骼、权重、挥手动作)
    storage.js         导入导出、WebM 录制
  views/               五个页面
  store/project.js     Pinia 工程状态 + 本地持久化
```
